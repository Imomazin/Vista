## Design principle

All selected photos should be accessible in the product, but **not all 37 must compete in the first viewport**. Present them as cinematic framing, relevant engine hero imagery, a few editorial story bands, and curated galleries/visual explainers within each studio. Preserve real functional dashboards and evidence: imagery is illustration, not measured AI output or actual customer analytics.

### The definitive hybrid

- **Titanium and platinum**: environment, frames, panels, whitespace and executive trust.
- **Emerald**: evidence signals, action controls, selected nodes and the capital T in VisTa.
- **Violet**: a restrained futuristic layer within cinematic transitions, advanced AI/GEO, content creation and ambient backlighting. It never becomes a third dominant UI background colour.
- **Human photography**: confidence, creative process and commercial relevance.

Suggested violet tokens: dark `#A88BFF`, light `#7456B6`; use 8–14% opacity atmospheric fields and clearer tones only for explicitly identified AI/creative accents. Do not tint human skin or alter the factual contents of charts embedded in photos.

## Engineering specification

- Store the original uploads once at their mapped descriptive path. Additional identical selections are metadata references, not redundant image copies.
- Use Next.js image optimisation, explicit intrinsic dimensions, responsive `sizes`, loading priority only for the selected hero/LCP image and lazy loading elsewhere.
- Use `object-fit:cover` only where a safe crop preserves essential chart or figure content. Use `contain` for logos and text-heavy educational images.
- Store `alt` text per asset, with empty alt only when duplicated decoration. Do not treat stock visuals as data provenance.
- Add restrained violet/emerald gradients, edge lights and metallic frames; avoid destructive photographic colour filters and people-skin recolouring.
- Dark: platinum edge, deep obsidian scrims, emerald and violet illumination; Light: porcelain frames, delicate titanium shadows, emerald focal lines and whisper-soft violet atmospheric treatment.
- Avoid placing photos behind small text. Maintain WCAG contrast and reduced-motion.
- Link each prominent panel to an actual functionality, not a dead decorative button.
- Test that every referenced path resolves successfully before committing front-end image placements.
- Add visual screenshot checks at desktop/tablet/mobile for both themes, verify performance, cropping, alt text, and licence approval.
- Preserve existing live HTML audits, evidence schema, source integrity, keyboard navigation and all saved data.
