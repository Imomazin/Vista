# VisTa Web Images — Image Library

Permanent public website asset path: `public/web-images`. This directory is a catalogue for **all 41 user selections (38 distinct original images including Ambidexters logo)**. Three images were exact repeats across batches; they are referenced rather than physically copied twice.

The complete prepared image pack retains the original source resolution, descriptive filenames and includes Ambidexters transparent PNG variants for dark and light themes.

**Status:** The text catalogue is committed here, but the binary photos are **not yet in this GitHub branch**. The asset pack is attached separately in the conversation for transfer. Do not enable image URLs in live JSX until their actual binary files have been committed and verified. The folder should contain the thematic subfolders in the catalogue after import.

**Folders:** brand, cinematic, analytics, impact, authority, agency, ai-exposure, reputation, content, search, site.

Use selectively as images across VisTa's cinematic entrance, the Command Centre, the nine engines, evidence/story panels, and educational visual galleries. All selected assets must be accessible somewhere in the product; avoid treating photos as authentic live dashboards or measured data. Preserve the Titanium, Emerald and Violet design treatment around images rather than destructively recolouring photos.

Public reuse or publication of third-party imagery may require permission; confirm licences for public GitHub and public website before publishing. See `docs/image-placement-blueprint.md` for section-by-section implementation.
